# SYNTRA 2030 — Digital Twin

A futuristic personal digital twin dashboard built with plain HTML, CSS, and vanilla JavaScript. It runs locally without a server, backend, framework, database, or external API.

## Run it

Open `index.html` in a modern browser. The Google Fonts import is optional; if you are offline, the page uses system font fallbacks.

## Explore

- Initialize the dashboard from the landing screen.
- Adjust the five life metric sliders. Productivity, stress, metric cards, and forecast levels update from the current inputs.
- Start the future simulation to see its staged model sequence.
- Select a What If scenario to compare projected productivity and stress.
- Use the navigation to move between dashboard sections.

## Files

- `index.html` — page structure and dashboard content
- `style.css` — responsive visuals, animation, and layout
- `script.js` — slider calculations, simulation, and scenario interactions
- `.gitignore` — common local editor and OS artifacts

All calculations are illustrative client-side models for this fictional concept.
